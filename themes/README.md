# EasyMD Themes

把自定义主题 CSS 放在这个目录下，EasyMD 会自动读取 `themes/*.css` 并显示在主题下拉列表中。

Place custom theme CSS files in this folder. EasyMD automatically reads `themes/*.css` and shows them in the theme dropdown.

建议从 `example_theme/easymd-theme-template.css` 复制一份开始修改。

Start by copying `example_theme/easymd-theme-template.css`.
